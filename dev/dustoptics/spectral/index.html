Optical lookup tables

PlanetPostStats.DustOptics.OpticalCoefficients — Type
OpticalCoefficients

Optical properties of the size bins at the diagnostic wavelengths of one SpectralSet, as returned by interpolate_coefficients.

Fields

  • name::String: name of the spectral set.
  • wavelengths::Vector{Float64}: diagnostic wavelengths (m).
  • k_scat, k_abs::Matrix{Float64}: mass scattering and absorption coefficients (m² kg⁻¹), (wavelength, bin).
  • g_asym::Matrix{Float64}: asymmetry parameter, (wavelength, bin).

Example

c = interpolate_coefficients(sw, bins)
c.k_scat[1, :] .+ c.k_abs[1, :]           # mass extinction coefficients at λ₁

PlanetPostStats.DustOptics.SpectralSet — Type
SpectralSet(name, table, wavelengths; coefficients_file=nothing)

Diagnostic wavelengths of one spectral range (e.g. shortwave or longwave) and the optical lookup table from which their optical properties are interpolated.

Arguments

  • name::AbstractString: name of the set (e.g. "sw"), used in the variable names of the coefficient file.
  • table::SpectralTable: optical properties in the bands of the radiation code.
  • wavelengths::AbstractVector{<:Real}: diagnostic wavelengths (m), positive, with unique wavelength_labels.

Keyword arguments

  • coefficients_file = nothing: if a path is given, the coefficients interpolated to the wavelengths and the size bins are written to this NetCDF file (write_coefficients).

Example

sw = SpectralSet("sw", read_spectral_table("aer_sw.nc", "sw_bands.csv"), [0.55e-6, 0.89e-6])

PlanetPostStats.DustOptics.SpectralTable — Type
SpectralTable(band_bounds, radius, k_scat, k_abs, g_asym)

Optical properties of one aerosol component in the spectral bands of a radiation code, tabulated for a set of particle effective radii (e.g. the aerosol optical-property files of SOCRATES used by ROCKE-3D).

Fields

  • band_bounds::Vector{Tuple{Float64,Float64}}: (lower, upper) wavelength bounds of the bands (m).
  • radius::Vector{Float64}: effective radii of the table (m).
  • k_scat::Matrix{Float64}: mass scattering coefficient (m² kg⁻¹), (band, radius).
  • k_abs::Matrix{Float64}: mass absorption coefficient (m² kg⁻¹), (band, radius).
  • g_asym::Matrix{Float64}: asymmetry parameter, (band, radius).

Row i of the matrices belongs to band i of band_bounds. The constructor checks the sizes and that the bounds and radii are positive.

See also read_spectral_table, interpolate_coefficients.

Example

julia> t = SpectralTable([(0.4e-6, 0.6e-6), (0.6e-6, 1.0e-6)], [1e-7, 1e-6],
                         [1.0 2.0; 3.0 4.0], [0.1 0.2; 0.3 0.4], [0.6 0.7; 0.6 0.7]);

julia> size(t.k_scat)
(2, 2)

PlanetPostStats.DustOptics.interpolate_coefficients — Method
interpolate_coefficients(set::SpectralSet, bins; extrapolation=:linear)
    -> OpticalCoefficients

Interpolates the mass scattering and absorption coefficients and the asymmetry parameter of set.table to the wavelengths set.wavelengths and the effective radii of the size bins, with PlanetTools.PlanetAerosolUtils.interpolate_extinction_coeff_log: linear in log(value) versus log(wavelength) and log(radius), each band placed at the geometric mean of its bounds.

Arguments

  • set::SpectralSet: wavelengths and lookup table.
  • bins::AbstractVector{DustBin}: size bins.

Keyword arguments

  • extrapolation::Symbol = :linear: treatment of wavelengths and radii outside the table, :linear (power laws), :flat, or :error.

Example

c = interpolate_coefficients(sw, bins)
size(c.k_scat)                             # (length(sw.wavelengths), length(bins))

PlanetPostStats.DustOptics.read_band_bounds — Method
read_band_bounds(path; header_row=3, band_column="Band") -> Vector{Tuple{Float64,Float64}}

Reads the wavelength bounds of the spectral bands from the CSV file path, with CSV.jl.

The column names are in line header_row of the file (the lines above are skipped, e.g. comments), followed by one line per band. Besides the column band_column with the band number, the file must have exactly two numeric columns, the lower and upper wavelength bound of the band (m); the order of the two does not matter. The bands are returned in the order of the file, which must be the order of the bands in the optical-property file (see read_spectral_table).

Arguments

  • path::AbstractString: CSV file.

Keyword arguments

  • header_row::Integer = 3: line with the column names.
  • band_column::AbstractString = "Band": name of the column with the band numbers; ignored if absent.

Example

bounds = read_band_bounds("sp_sw_bands.csv")
bounds[1]                                  # (lower, upper) of band 1 in m

PlanetPostStats.DustOptics.read_spectral_table — Method
read_spectral_table(spectral_file, bands_file; header_row=3, humidity_index=1,
                    component_index=1) -> SpectralTable

Reads the optical properties of one aerosol component from the NetCDF file spectral_file and the wavelength bounds of its bands from the CSV file bands_file (read_band_bounds).

Variables read from spectral_file (dimensions in Julia order):

  • radius_eff_dry(radius, component): dry effective radius (m);
  • k_scat, k_abs, g_asym(band, humidity, radius, component): mass scattering and absorption coefficients (m² kg⁻¹) and asymmetry parameter.

The table of humidity humidity_index and component component_index is used. The number of bands of the two files must agree; the bands are paired in file order.

Arguments

  • spectral_file::AbstractString: NetCDF file of optical properties.
  • bands_file::AbstractString: CSV file of band bounds.

Keyword arguments

  • header_row::Integer = 3: header line of bands_file.
  • humidity_index::Integer = 1, component_index::Integer = 1: table to use.

Example

sw = read_spectral_table("aer_sw_dust.nc", "sp_sw_bands.csv")
length(sw.band_bounds), length(sw.radius)

PlanetPostStats.DustOptics.write_coefficients — Method
write_coefficients(path, c::OpticalCoefficients, bins) -> String

Writes the interpolated optical properties c of the size bins to the NetCDF file path (created or overwritten; parent directories are created), with PlanetTools.ReadWritePlanet.writenetcdf: variables diag_k_scat_<name>, diag_k_abs_<name> (m² kg⁻¹), and diag_g_asym_<name> on the dimensions wavelength (m) and radius_eff_dry (m, the effective radii of the bins), where <name> is c.name. Returns path.

Example

write_coefficients("aer_sw_interpol.nc", interpolate_coefficients(sw, bins), bins)
