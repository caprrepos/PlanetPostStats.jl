PlanetPostStats.DustOptics.OPTICAL_QUANTITIES — Constant
OPTICAL_QUANTITIES

Optical quantities that can be computed, with the prefix of their variable names and the first word of their long names: :sct (scattering), :abs (absorption), and :ext (extinction = scattering + absorption).

Example

PlanetPostStats.DustOptics.DustOpticsConfig — Type
DustOpticsConfig(; stats, bins, input_dir, input_name, kwargs...)

All settings of the optical post-processing of dust, run_dust_optics.

The input are the monthly time series of the dust tracer mass mixing ratios and of the air mass of the layers written by PlanetPostStats.TimeSeriesMeSd (<prefix>.<input_name><run>.<input_tag>.mts.nc in <input_root>/<run>/<input_dir>/MonthlyTs/). From these, for every run and month, the dust masses of the size bins in the model layers are formed, and from them

  • the effective radius of the dust in the layers (effRad3d_<class>), of the column dust load (effRadColMass_<class>), and its mass-weighted column average (effRadColAve_<class>), where <class> is the largest size class of optics_classes (e.g. PM32Dust), or Dust for other bins;
  • for every SpectralSet, diagnostic wavelength, and quantity of quantities, the optical depth of every bin and every size class in the layers (<q>3d_<λ>_<bin>, e.g. ext3d_550nm_Clay1) and of the column (<q>2d_<λ>_<bin>, e.g. ext2d_550nm_PM32Dust), and the opacity profiles in the layers selected by opacity_profiles: the opacity per kilometer (<q>km_<λ>_<bin>, e.g. extkm_21600nm_PM32Dust, km⁻¹; opacity_per_km) and the density-scaled opacity, the optical depth of a layer divided by its air mass (<q>dso_<λ>_<bin>, e.g. extdso_21600nm_PM32Dust, m² kg⁻¹; density_scaled_opacity).

All variables are then processed like the variables of TimeSeriesMeSd (time series, multi-year means and standard deviations; gridded, zonal, and global means), with the settings of stats.

Required keyword arguments

  • stats::TimeSeriesConfig: runs, periods, calendar, seasons, time axis, vertical coordinate, optional pressure levels, threshold, products, and output settings (simpath, output_dir, output_name, global_attributes, …). Its groups and derived are not used and should be empty.
  • bins::Vector{DustBin}: size bins of the optical calculations, in the order of accumulation of the size classes.
  • input_dir::String: subdirectory of a run with the TimeSeriesMeSd output of the dust tracers (its output_dir, e.g. "Tracermass3d").
  • input_name::String: tag of these files (its output_name, e.g. "tracermass3d").

Optional keyword arguments

  • spectral::Vector{SpectralSet} = SpectralSet[]: spectral ranges, wavelengths, and lookup tables; empty: only effective radii.
  • fractions = nothing: fractions of the source tracer mass in the bins, one value per bin: a vector (all runs), a Dict from run identifier to vector, or a function run -> vector; nothing: all fractions 1. See bin_fractions. The fractions of the bins of one source should sum to 1.
  • input_root = nothing: directory with one subdirectory per run for the input; nothing: stats.simpath.
  • input_tag::String = "ijl": representation tag of the input files (gridded, model levels).
  • input_prefix = nothing: period prefix of the input file names (e.g. "JAN0001-DEC0020"); nothing: the single file matching *.<input_name><run>.<input_tag>.mts.nc.
  • airmass::String = "airmass": input variable with the air mass of the layers per unit area (kg m⁻²).
  • quantities::Vector{Symbol} = [:sct, :abs, :ext]: optical quantities, see OPTICAL_QUANTITIES.
  • layers::Bool = true: output the optical depths of the layers (3D).
  • columns::Bool = true: output the column optical depths (2D).
  • bin_variables::Bool = true: output the optical depths of the individual bins.
  • class_variables::Bool = true: output the optical depths of the size classes.
  • extrapolation::Symbol = :linear: extrapolation of the lookup tables, see interpolate_coefficients.
  • effective_radius_to_pressure::Bool = true: interpolate the effective radius of the layers to pressure levels when stats.pressure_levels is set.
  • opacity_profiles::Vector{Symbol} = [:per_km]: opacity profiles of the layers (3D) to output, a subset of :per_km (opacity per kilometer, the quantity of the dust profiles retrieved by the Mars Climate Sounder) and :density_scaled (opacity per unit air mass); empty: none. Both do not depend on the layer thickness and are interpolated to pressure levels when stats.pressure_levels is set; the optical depths of the layers are layer-integrated quantities and are never interpolated.
  • temperature::String = "TempL": input variable with the temperature of the layers (K or °C, from its units attribute), for the air density of :per_km.
  • gas_constant::Float64 = 188.92: specific gas constant of the atmosphere (J kg⁻¹ K⁻¹; CO₂: 8.314462618 / 0.0440095) for the air density of :per_km.
  • surface_pressure::String = "prsurf": input variable with the surface pressure (hPa), for the air density of :per_km.

The opacity per kilometer needs the layer temperature and the surface pressure in the input files, and stats.vertical; the air density is computed with air_density. With stats.pressure_levels, the surface pressure of the pressure levels (stats.pressure_levels.surface_pressure) must be contained in the input files. These auxiliary variables are read but not written.

Example

stats = TimeSeriesConfig(; simpath="/path/to/simulations", runs=["MarsDustRun1"],
    sim_period=(YearMonth(1, 1), YearMonth(20, 12)),
    stat_period=(YearMonth(3, 1), YearMonth(20, 12)), calendar=MARS_CALENDAR,
    seasons=MARS_SEASONS, output_dir="Traceroptics3d", output_name="traceroptics3d")
bins = [DustBin("Clay1"; source="Clay", radius=0.132e-6, density=2.5e3), …]
cfg = DustOpticsConfig(; stats=stats, bins=bins, spectral=[sw, lw],
    fractions=bin_fractions(bins, "Clay" => [0.009, 0.081, 0.234, 0.676]),
    input_dir="Tracermass3d", input_name="tracermass3d")

PlanetPostStats.DustOptics.OpticsVariableSpec — Type
OpticsVariableSpec

Description of one output variable of the optical post-processing (internal).

Fields

  • name::String, long_name::String, units::String.
  • kind::Symbol: :reff3d, :reffcolmass, :reffcolave, :tau (optical depth), :km (opacity per kilometer), or :dso (density-scaled opacity).
  • is3d::Bool: layer (3D) or column (2D) variable.
  • coefficients::Vector{Float64}: for :tau, :km, and :dso, coefficient of every bin (m² kg⁻¹; zero for bins not included).

Example

specs = optics_variable_specs(cfg, coefficients)
first(specs).name                          # "effRad3d_PM32Dust"

PlanetPostStats.DustOptics.effective_radius_suffix — Method
effective_radius_suffix(bins) -> String

Suffix of the names of the effective-radius variables: the largest size class of optics_classes(bins) (e.g. "PM32Dust"), or "Dust" if there is none.

Example

julia> effective_radius_suffix([DustBin("x"; radius=1e-6, density=2500)])
"Dust"

PlanetPostStats.DustOptics.optics_variable_names — Method
optics_variable_names(cfg::DustOpticsConfig) -> Vector{String}

Names of all output variables of the optical post-processing, in output order: the effective radii, then, for every spectral set, quantity, wavelength, and for the optical depths of the layers and the column and the density-scaled opacities, the bins followed by the size classes.

Example

julia> optics_variable_names(cfg)[1:3]
3-element Vector{String}:
 "effRad3d_PM32Dust"
 "effRadColMass_PM32Dust"
 "effRadColAve_PM32Dust"

PlanetPostStats.DustOptics.optics_variable_specs — Method
optics_variable_specs(cfg::DustOpticsConfig, coefficients) -> Vector{OpticsVariableSpec}

Descriptions of all output variables (see optics_variable_names). coefficients are the OpticalCoefficients of the spectral sets, in the order of cfg.spectral; with nothing, only names and attributes are formed (zero coefficients), e.g. for validation.

Example

coefs = [interpolate_coefficients(s, cfg.bins) for s in cfg.spectral]
specs = optics_variable_specs(cfg, coefs)

PlanetPostStats.DustOptics.run_fractions — Method
run_fractions(cfg::DustOpticsConfig, run) -> Vector{Float64}

Fractions of the source tracer mass in the bins for run run, from cfg.fractions (vector, Dict by run, function of the run, or nothing for all ones). Throws an ArgumentError if the number of fractions differs from the number of bins, a fraction is negative or not finite, or a Dict has no entry for the run; warns if the fractions of the bins of one source do not sum to 1 (within 10⁻³).

Example

julia> run_fractions(cfg, "MarsDustRun1")

PlanetPostStats.DustOptics.validate_optics_config — Method
validate_optics_config(cfg::DustOpticsConfig) -> DustOpticsConfig

Checks the configuration and throws an ArgumentError describing the first problem found: cfg.stats with validate_config (without input groups, with the output variable names and the surface pressure of the pressure levels); at least one bin; unique bin names; unique spectral-set names; known quantities; non-empty input directory and name; unique output variable names. Returns cfg.

Example

validate_optics_config(cfg);               # throws if cfg is inconsistent
