PlanetPostStats.DustOptics.input_file — Method
input_file(cfg::DustOpticsConfig, run) -> String

Path of the monthly time-series file with the dust tracers of run, written by TimeSeriesMeSd: in <input_root>/<run>/<input_dir>/MonthlyTs/ (input_root defaults to cfg.stats.simpath), the file <input_prefix>.<input_name><run>.<input_tag>.mts.nc if cfg.input_prefix is set, otherwise the only file whose name ends with .<input_name><run>.<input_tag>.mts.nc. Throws an ArgumentError if no file or more than one file is found.

Example

julia> input_file(cfg, "MarsDustRun1")
"/path/to/simulations/MarsDustRun1/Tracermass3d/MonthlyTs/JAN0001-DEC0020.tracermass3dMarsDustRun1.ijl.mts.nc"

PlanetPostStats.DustOptics.layer_air_density — Method
layer_air_density(cfg::DustOpticsConfig, ds, path, tidx, plm) -> Array{Float32,4}

Air density (kg m⁻³) of the model layers of the open input dataset ds (file path) for the time indices tidx, with air_density from the surface pressure cfg.surface_pressure (hPa), the layer temperature cfg.temperature (K or °C, see temperature_offset; kelvin assumed with a warning if the variable has no units attribute), the reference mid-layer pressures plm, cfg.stats.vertical, and cfg.gas_constant.

Example

NCDataset(path) do ds
    layer_air_density(cfg, ds, path, 1:240, ds["plm"][:])
end

PlanetPostStats.DustOptics.load_optics_run — Method
load_optics_run(cfg::DustOpticsConfig, coefficients, run) -> RunData

Reads the dust tracers and the air mass of run from its input_file and returns the RunData of the optical post-processing, whose variables are LazyVariables computed when they are written (see DustOpticsConfig).

Procedure

  1. Reads the months (year, month) of the file and keeps those within cfg.stats.sim_period, which must form a contiguous record.
  2. Reads the grid: lon, lat, the vertical coordinate of the tracers, the reference pressures plm and ple (if present), and the cell areas cfg.stats.area_variable.
  3. Reads the mass mixing ratios of the source tracers of cfg.bins (kg kg⁻¹) and the air mass cfg.airmass (kg m⁻²), and forms the dust mass per unit area of every source in every layer, q · m_air (DustBinMasses, with the fractions of run_fractions). Only these source masses (and, for the density-scaled opacities, the air mass) are held in memory.
  4. With cfg.stats.pressure_levels, reads the surface pressure as auxiliary variable.
  5. For the opacities per kilometer, computes the air density of the layers from the layer temperature and the surface pressure (layer_air_density); the air mass and the air density are then also held in memory.

coefficients are the OpticalCoefficients of cfg.spectral (in order).

Example

coefs = [interpolate_coefficients(s, cfg.bins) for s in cfg.spectral]
rd = load_optics_run(cfg, coefs, "MarsDustRun1")
collect(keys(rd.variables))[1:3]

PlanetPostStats.DustOptics.optics_variables — Method
optics_variables(cfg::DustOpticsConfig, coefficients, m::DustBinMasses;
                 airmass=nothing, density=nothing) -> OrderedDict{String,AnyVariable}

The output variables of one run as LazyVariables, in the order of optics_variable_names: each computes its field from the bin masses m when it is written (effective_radius, column_mean_effective_radius, combine_bins of m or of column_masses(m), opacity_per_km, density_scaled_opacity). The column masses are computed once, on first use. The opacity profiles need the air mass of the layers, airmass (kg m⁻²), the opacities per kilometer also the air density, density (kg m⁻³); both profiles are interpolated to pressure levels when cfg.stats.pressure_levels is set, the optical depths of the layers are not.

Example

vars = optics_variables(cfg, coefs, m)
size(field(vars["ext2d_550nm_PM32Dust"]))   # (lon, lat, time)

PlanetPostStats.DustOptics.read_field — Method
read_field(ds, name, tidx) -> Array{Float32}

Reads the variable name of the open dataset ds for the time indices tidx (last dimension) as Float32; missing values (fill values) become NaN32.

Example

NCDataset(path) do ds
    read_field(ds, "Clay", 1:240)          # (lon, lat, level, 240)
end

PlanetPostStats.DustOptics.temperature_offset — Method
temperature_offset(units) -> Float64

Offset (K) that converts a temperature with the units attribute units to kelvin: 0 for kelvin (K, kelvin, degK), 273.15 for degrees Celsius (C, degC, deg C, °C, degrees_C, degree_Celsius, Celsius); case-insensitive. Throws an ArgumentError for other units.

Example

julia> temperature_offset("degC"), temperature_offset("K")
(273.15, 0.0)
