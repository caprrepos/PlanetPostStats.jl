PlanetPostStats.TimeSeriesMeSd.interpolate_to_pressure — Method
interpolate_to_pressure(x, ps, plm, vc, plev) -> Array{Float32,4}

Interpolates the monthly 3D field x from the model layers to the pressure levels plev.

For every column and month, the mid-layer pressures p₁ > p₂ > … > p_L of the model layers are computed from the surface pressure ps of that column and month with layer_pressure. For a pressure level P:

  • P > ps (below the local surface): missing (NaN32);
  • ps ≥ P ≥ p₁ (between the surface and the mid-point of the lowest layer): value of the lowest layer;
  • p_l ≥ P ≥ p_{l+1}: linear interpolation in ln p between layers l and l + 1, x = x_l + (ln P − ln p_l) / (ln p_{l+1} − ln p_l) · (x_{l+1} − x_l);
  • P < p_L (above the mid-point of the uppermost layer): missing.

The result is missing where a value of the two bracketing layers or the surface pressure is missing. The loop over the columns is multi-threaded. Throws an ArgumentError if plm does not match vc (check_sigma_layers).

Arguments

  • x::AbstractArray{<:Real,4}: field (lon, lat, layer, time), layer 1 at the bottom; missing values NaN.
  • ps::AbstractArray{<:Real,3}: surface pressure (lon, lat, time), same unit as plm and plev (hPa).
  • plm::AbstractVector{<:Real}: reference mid-layer pressures of the layers.
  • vc::VerticalCoordinate: parameters of the vertical coordinate.
  • plev::AbstractVector{<:Real}: target pressure levels.

Returns

Array{Float32,4} of size (lon, lat, length(plev), time).

Example

julia> vc = VerticalCoordinate(3, 10.0, 1.0);   # layers 1, 2 σ; layer 3 pressure

julia> plm = [9.0, 5.0, 0.5];

julia> x = reshape(Float32[log(9.0), log(5.0), log(0.5)], 1, 1, 3, 1);  # x = ln p

julia> ps = fill(10.0f0, 1, 1, 1);

julia> y = interpolate_to_pressure(x, ps, plm, vc, [12.0, 9.5, 7.0, 2.0, 0.1]);

julia> isnan(y[1]), y[2] ≈ log(9.0), y[3] ≈ log(7.0), y[4] ≈ log(2.0), isnan(y[5])
(true, true, true, true, true)

PlanetPostStats.TimeSeriesMeSd.layer_pressure — Method
layer_pressure(ps, plm_l, l, vc::VerticalCoordinate) -> Float64

Mid-layer pressure of model layer l in a column with surface pressure ps.

For the σ layers (l < vc.ls1) the pressure follows the surface pressure, p = p_top + σ (ps − p_top) with σ = (plm_l − p_top) / (p_sf − p_top), where plm_l is the reference mid-layer pressure of the layer (plm in the input files) and p_sf, p_top are vc.psf and vc.ptop. For the pure pressure layers (l ≥ vc.ls1) the pressure is plm_l. All pressures are in the same unit (hPa).

Arguments

  • ps::Real: surface pressure of the column.
  • plm_l::Real: reference mid-layer pressure of layer l.
  • l::Integer: layer index (1 = lowest layer).
  • vc::VerticalCoordinate: parameters of the vertical coordinate.

Example

julia> vc = VerticalCoordinate(31, 6.86, 0.2);

julia> layer_pressure(6.86, 5.0, 1, vc)      # reference column: plm itself
5.0

julia> layer_pressure(8.0, 5.0, 1, vc) ≈ 0.2 + 4.8 * 7.8 / 6.66
true

PlanetPostStats.TimeSeriesMeSd.model_level_bounds — Method
model_level_bounds(plm, ple, psf) -> Matrix{Float64}

Reference pressures at the edges of the model layers as CF cell bounds of size (2, L): bounds[1, l] is the lower edge of layer l (psf for the lowest layer, the upper edge ple[l - 1] of the layer below otherwise), bounds[2, l] = ple[l] its upper edge. These are the edge pressures of the hybrid σ–pressure layers in a column with surface pressure psf (VerticalCoordinate.psf); ple is the variable of the same name in the scaleacc files, which also defines σ at the layer edges.

Throws an ArgumentError unless plm and ple have the same length and every reference mid-layer pressure lies inside its layer, lower edge > plm[l] > ple[l] ≥ 0.

Arguments

  • plm::AbstractVector{<:Real}: reference mid-layer pressures (layer 1 at the bottom).
  • ple::AbstractVector{<:Real}: reference upper-edge pressures of the layers.
  • psf::Real: reference surface pressure.

Example

julia> model_level_bounds([5.0, 1.0], [3.0, 0.2], 6.86)
2×2 Matrix{Float64}:
 6.86  3.0
 3.0   0.2

PlanetPostStats.TimeSeriesMeSd.output_pressure_bounds — Function
output_pressure_bounds(cfg::TimeSeriesConfig, plm=nothing, ple=nothing)
    -> Union{Nothing,Matrix{Float64}}

Pressures (hPa) at the edges of the layers of the output pressure levels output_pressure_levels(cfg, plm), as CF cell bounds of size (2, number of levels), written as plev_bnds:

  • for levels = :model and the upper-edge pressures ple of the input files given (e.g. rd.grid.ple): the reference edge pressures of the model layers, model_level_bounds(plm, ple, cfg.vertical.psf);
  • otherwise: the midpoints in ln p between the levels, pressure_level_bounds.

Returns nothing for a single level without ple (no edges can be derived).

Arguments

  • cfg::TimeSeriesConfig: configuration with pressure_levels.
  • plm = nothing, ple = nothing: reference mid-layer and upper-edge pressures of the input files (hPa).

Example

julia> cfgm = TimeSeriesConfig(; cfg_kwargs..., vertical=VerticalCoordinate(31, 6.86, 0.2),
                               pressure_levels=PressureLevels(:model));

julia> output_pressure_bounds(cfgm, Float32[5, 1], Float32[3, 0.2])[:, 1]
2-element Vector{Float64}:
 6.86
 3.0

PlanetPostStats.TimeSeriesMeSd.pressure_level_bounds — Method
pressure_level_bounds(levels) -> Matrix{Float64}

Pressures at the edges of the layers represented by the pressure levels levels, as CF cell bounds of size (2, length(levels)): bounds[1, k] is the lower edge (higher pressure) and bounds[2, k] the upper edge (lower pressure) of the layer of level levels[k].

With the levels sorted by decreasing pressure, p₁ > p₂ > … > p_n, the edge between two neighboring levels is their geometric mean, i.e. the midpoint in ln p (the coordinate in which interpolate_to_pressure interpolates linearly),

p_{k+1/2} = √(p_k p_{k+1}),

and the outer edges lie half a level spacing in ln p beyond the outermost levels, p_{1/2} = p₁ √(p₁/p₂) and p_{n+1/2} = p_n √(p_n/p_{n−1}). Adjacent layers share their edges, all edges are positive, and every level lies inside its layer. The levels may be given in any order; the bounds refer to levels[k] in the given order. At least two levels are needed.

Arguments

  • levels::AbstractVector{<:Real}: positive, unique pressure levels.

Returns

Matrix{Float64} of size (2, length(levels)).

Example

julia> b = pressure_level_bounds([4.0, 1.0, 0.25]);

julia> b[:, 2]                     # layer of 1 hPa: edges √(4·1) and √(1·0.25)
2-element Vector{Float64}:
 2.0
 0.5

julia> b[1, 1], b[2, 3]            # outer edges: 4·√4 and 0.25·√0.25
(8.0, 0.125)
