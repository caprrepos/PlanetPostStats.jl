PlanetPostStats.TimeSeriesMeSd.PlanetCalendar — Type
PlanetCalendar(name, days_in_month; day_length="", month_names=DEFAULT_MONTH_NAMES)

Model calendar of a planet: the lengths of the 12 model months and descriptive metadata.

The month lengths are used as weights when monthly means are averaged into seasonal and annual means: month m gets the weight days_in_month[m] / days_in_year(calendar). The unit of days_in_month is irrelevant for the weights (only ratios enter), but by convention it is the number of local solar days (sols on Mars).

Arguments

  • name::AbstractString: planet or calendar name, written to the output metadata.
  • days_in_month: 12 month lengths (any real numbers > 0), in local days.

Keyword arguments

  • day_length::AbstractString = "": length of one local day with unit, e.g. "88775.245 seconds" for Mars; written as attribute day_length of the time coordinate (omitted when empty).
  • month_names: 12 three-letter month labels used in output file names.
  • cf_calendar::AbstractString = lowercase(name): value of the CF calendar attribute of the time coordinate. A name that is not a CF standard calendar (e.g. "mars") declares a user-defined calendar, whose month lengths are written as attribute month_lengths; CF readers then do not convert the time values into Earth dates.

Predefined calendars

  • MARS_CALENDAR: ROCKE-3D Mars calendar, months of 61, 66, 66, 65, 60, 54, 50, 47, 46, 47, 51, 56 sols (669 sols per year).
  • EARTH_NOLEAP_CALENDAR: ModelE 365-day calendar without leap years.

Example

julia> cal = PlanetCalendar("TOI-700d", fill(10.0, 12); day_length="864000 seconds");

julia> days_in_year(cal)
120.0
source
PlanetPostStats.TimeSeriesMeSd.SeasonSpec — Type
SeasonSpec(name::AbstractString, first_month::Integer, length::Integer)

A season of length consecutive months starting in month first_month. Seasons may wrap into the following year (e.g. SeasonSpec("DJF", 12, 3)); the season is then labeled with the year of its first month (the year of the December). name is used in output file names, e.g. FMA_0001-0020.<name><run>.ij.sts.nc.

Arguments

  • name: label of the season (e.g. "JJA").
  • first_month: first month, 1 ≤ first_month ≤ 12.
  • length: number of months, 1 ≤ length ≤ 12.

Predefined season sets

  • EARTH_SEASONS: DJF, MAM, JJA, SON.
  • MARS_SEASONS: FMA, MJJ, ASO, NDJ.

Example

julia> s = SeasonSpec("NDJ", 11, 3)
SeasonSpec("NDJ", 11, 3)

julia> season_months(s)
3-element Vector{Int64}:

  1

PlanetPostStats.TimeSeriesMeSd.TimeAxis — Type
TimeAxis(reference::YearMonth, units::AbstractString)
TimeAxis(; reference=YearMonth(0, 12), units="months since 0000-12")

Definition of the numerical time coordinate written to the time-series output files.

The coordinate value of a period (month, season, or year) is the number of months from reference to the first month of that period, months_between(reference, first). One common unit (months) is therefore used for monthly, seasonal, and annual series. The string units is written verbatim as the units attribute and must describe reference in the convention of the user.

With the default reference = YearMonth(0, 12), the first month of model year 1 (YearMonth(1, 1)) has the coordinate value 1, so a monthly series starting in January of year 1 has time = 1, 2, …, n.

In addition, every time-series file contains the integer variables year(time) and month(time) with the first model month of each period, which are unambiguous irrespective of the units string.

Example

julia> ax = TimeAxis(; reference=YearMonth(0, 12), units="months since 0023-12-56");

julia> time_value(ax, YearMonth(2, 1))
13
source
PlanetPostStats.TimeSeriesMeSd.YearMonth — Type
YearMonth(year::Integer, month::Integer)

Label of one model month: model year year (any integer, typically ≥ 1 for ModelE and ROCKE-3D runs) and month month (1 … 12). YearMonths are totally ordered (earlier < later), can be shifted by an integer number of months with +/-, and the number of months between two labels is obtained with months_between.

The type deliberately carries no information on the length of a month; that is a property of the PlanetCalendar.

Arguments

  • year::Integer: model year.
  • month::Integer: month of the year, 1 ≤ month ≤ 12; anything else throws an ArgumentError.

Example

julia> a = YearMonth(3, 11)
YearMonth(3, 11)

julia> a + 3
YearMonth(4, 2)

julia> months_between(YearMonth(1, 1), a)
34

julia> YearMonth(1, 12) < YearMonth(2, 1)
true
source

PlanetPostStats.TimeSeriesMeSd.climatology_slots — Method
climatology_slots(months, window) -> Vector{Vector{Int}}

Record indices of every calendar month (1 … 12) to be used for the multi-year statistics of the annual cycle (mom, som products). Only complete calendar years that lie entirely inside window and inside the record are used, so that each calendar month is sampled the same number of times.

Returns a vector of 12 index vectors; element m contains the indices of month m.

Example

julia> months = yearmonth_range(YearMonth(1, 1), YearMonth(4, 6));

julia> slots = climatology_slots(months, (YearMonth(2, 3), YearMonth(4, 6)));

julia> slots[1]   # only year 3 is a full year inside the window
1-element Vector{Int64}:
 25
