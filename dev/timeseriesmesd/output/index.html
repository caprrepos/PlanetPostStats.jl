PlanetPostStats.TimeSeriesMeSd.OutputFile — Type
OutputFile

An output NetCDF file created by create_output_file. Data variables are added with write_field!, which appends to the file with PlanetTools.ReadWritePlanet.writenetcdf.

Fields

  • path::String: file path.
  • rep::Symbol: spatial representation (:ij, :zm, or :gm).
  • time_cell_method::String: temporal part of cell_methods (e.g. "time: annual mean").
  • has_time::Bool: whether variables get a time dimension.
  • level_dimname::String: name of the vertical dimension.

Example

of = create_output_file("x.nc", cfg, rd, :gm, true; time_cell_method="time: monthly mean",
                        time_months=rd.months)
write_field!(of, cfg, "z", gm_of_z, rd.variables["z"].attrib, :model)

PlanetPostStats.TimeSeriesMeSd.create_output_file — Method
create_output_file(path, cfg, rd, rep, has_model; has_plev=false, time_cell_method,
                   time_months=nothing, climatology=false,
                   extra_attributes=OrderedDict()) -> OutputFile

Creates the NetCDF file path (parent directories are created as needed) with PlanetTools.ReadWritePlanet.writenetcdf and writes dimensions, coordinates, metadata, grid-cell area, and vertical-coordinate scalars. Data variables are added afterwards with write_field!.

Contents:

  • dimensions and coordinates lon, lat, the model-layer dimension (if has_model), the pressure-level dimension plev (if has_plev; hPa, values of output_pressure_levels(cfg, plm); with edge pressures it gets the attribute bounds = "plev_bnds"), and, for time series and climatologies, the unlimited dimension time;
  • for time series: time (months from cfg.time_axis.reference to the first month of each period, attributes from time_attributes), the integer variables year(time) and month(time), and the date strings Dates(time) ("YYYY-MM-01", as always written by writenetcdf);
  • for climatologies (mom, som): time = 1 … 12 and month(time);
  • plev_bnds(plev, nv) (if has_plev and edges can be derived): pressures (hPa) at the lower (nv = 1) and upper (nv = 2) edge of the layer of each pressure level, output_pressure_bounds (Psf and ple of the input files for model reference levels, otherwise midpoints in ln p between the levels);
  • plm, ple (reference pressures on the vertical dimension) and LS1, Psf, Ptop (if cfg.vertical is set) for files with variables on model levels;
  • the grid-cell area axyp (the name writenetcdf uses): cell areas (ij), the zonal mean of the cell areas (zm), or the total planetary area (gm);
  • global attributes: Experiment, cfg.global_attributes, Planet, Missing_data_threshold_percent, Seasonal_means_weighted_by_month_length, Standard_deviation, Vertical_interpolation (files with pressure levels), extra_attributes, Software, File_creation_time.

Arguments

  • path::AbstractString: output file path.
  • cfg::TimeSeriesConfig: configuration.
  • rd::RunData: data of the run (grid, run identifier).
  • rep::Symbol: :ij, :zm (lon of length 1, value 0), or :gm (lon and lat of length 1, value 0).
  • has_model::Bool: whether the file will contain variables on model levels.

Keyword arguments

  • has_plev::Bool = false: whether the file will contain variables on pressure levels.
  • time_cell_method::AbstractString: temporal part of cell_methods.
  • time_months = nothing: first month of every time step for time-series files.
  • climatology::Bool = false: annual-cycle file with time = 1 … 12.
  • extra_attributes: additional global attributes.

Example

of = create_output_file("ANN_0003_0020.prsurfRUN1.gm.moa.nc", cfg, rd, :gm, false;
                        time_cell_method="time: multi-year annual mean")
write_field!(of, cfg, "prsurf", moa, rd.variables["prsurf"].attrib, false)

PlanetPostStats.TimeSeriesMeSd.time_attributes — Method
time_attributes(cfg::TimeSeriesConfig) -> OrderedDict{String,Any}

Attributes of the time coordinate of the time-series files: units from cfg.time_axis, and the CF attributes of the model calendar, calendar (cfg.calendar.cf_calendar) and month_lengths (CF user-defined calendar), plus day_length if set. With a non-standard calendar (e.g. "mars"), CF-aware readers, including PlanetTools.ReadWritePlanet.readnetcdf, return the numerical time values instead of misinterpreting them as Earth dates.

Example

julia> time_attributes(TimeSeriesConfig(; cfg_kwargs..., calendar=MARS_CALENDAR))["calendar"]
"mars"

PlanetPostStats.TimeSeriesMeSd.write_field! — Method
write_field!(of::OutputFile, cfg, name, data, attrib, vertical::Symbol)

Appends the Float32 variable name with values data to the output file of with PlanetTools.ReadWritePlanet.writenetcdf.

data must have the dimensions (lon, lat[, level or plev][, time]) of the file (singleton lon/lat for zm/gm files); vertical is :none for 2D variables, :model for model levels, and :pressure for pressure levels. Missing values (NaN) are written as missing, i.e. as cfg.fill_value, which is set as _FillValue; writenetcdf encodes them correctly. The attribute cell_methods is composed from the file's temporal method and its spatial representation, e.g. "time: annual mean; lon: mean"; attrib (e.g. units, long_name) is copied. The variable is compressed with cfg.deflatelevel.

Example

write_field!(of, cfg, "prsurf", ats_gm, OrderedDict("units" => "hPa"), :none)
