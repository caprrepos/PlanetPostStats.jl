Input: scaleacc files

PlanetPostStats.TimeSeriesMeSd.ATTRIBUTES_TO_KEEP — Constant
ATTRIBUTES_TO_KEEP

Input variable attributes copied to the output, besides units and long_name, if present. Encoding attributes (scale_factor, add_offset, _FillValue, missing_value) are deliberately not copied: the input is decoded when read, and the output gets its own _FillValue.

Example

julia> "standard_name" in ATTRIBUTES_TO_KEEP
true

PlanetPostStats.TimeSeriesMeSd.TIME_LIKE_DIMS — Constant
TIME_LIKE_DIMS

Dimension names treated as a (singleton) time dimension in input variables and dropped when reading. scaleacc monthly files normally have no time dimension; this makes the reader robust against files that carry a time dimension of length one.

Example

julia> "time" in TIME_LIKE_DIMS
true

PlanetPostStats.TimeSeriesMeSd.GridInfo — Type
GridInfo

Horizontal and vertical grid of a run, read from the first available input files.

Fields

  • lon::Vector{Float32}, lat::Vector{Float32}: cell-center coordinates (degrees).
  • level::Union{Nothing,Vector{Float32}}: layer index coordinate (nothing if no 3D variable is processed).
  • plm, ple::Union{Nothing,Vector{Float32}}: reference mid-layer and upper-edge pressures (hPa) of the layers, if present in the input.
  • level_dimname::String: name of the vertical dimension in the input (e.g. "level").
  • area::Matrix{Float64}: grid-cell areas (axyp), size (lon, lat).
  • area_attrib::OrderedDict{String,Any}: attributes of the area variable.

Example

rd = load_run(cfg, "RUN1")
size(rd.grid.area) == (length(rd.grid.lon), length(rd.grid.lat))  # true

PlanetPostStats.TimeSeriesMeSd.LazyVariable — Type
LazyVariable(compute, attrib, is3d, to_pressure=true)

Monthly record of one variable of one run that is computed only when it is needed: compute() (a function without arguments) returns the values with the dimensions of VariableData.data. The output pipeline (process_run) calls it once, when the variable is processed, and releases the result before the next variable, so that a run can provide many more variables than fit into memory at the same time (e.g. optical depths for every size bin and wavelength derived from a few mass fields).

Fields

  • compute::Function: () -> AbstractArray{<:Real}; missing values NaN.
  • attrib::OrderedDict{String,Any}: output attributes (units, long_name, …).
  • is3d::Bool: true for variables with a vertical dimension.
  • to_pressure::Bool: as for VariableData.

Example

mass = rand(Float32, 4, 3, 2, 12)
tau = LazyVariable(() -> 0.5f0 .* mass, OrderedDict{String,Any}("units" => "1"), true, false)
size(field(tau))       # (4, 3, 2, 12)

PlanetPostStats.TimeSeriesMeSd.RunData — Type
RunData

All input data of one run, as returned by load_run.

Fields

  • run::String: run identifier.
  • months::Vector{YearMonth}: monthly record, from the first month of cfg.sim_period to the last month for which at least one input file exists.
  • grid::GridInfo: grid description.
  • variables::OrderedDict{String,AnyVariable}: variables written to the output, in output order (VariableData or LazyVariable).
  • available::Matrix{Bool}: available[g, t] is true if the input file g (input group of load_run) exists for, or contains, month t of months.
  • auxiliary::OrderedDict{String,AnyVariable}: variables needed for the processing but not written, e.g. the surface pressure for the interpolation to pressure levels when it is not an output variable. Variables are looked up in variables first.

The constructor with five arguments sets auxiliary empty.

Example

rd = load_run(cfg, "RUN1")
collect(keys(rd.variables))
source
PlanetPostStats.TimeSeriesMeSd.VariableData — Type
VariableData(data, attrib, is3d, to_pressure=true)

Monthly record of one variable of one run, held in memory.

Fields

  • data::Array{Float32}: values with dimensions (lon, lat, time) for 2D variables or (lon, lat, level, time) for 3D variables; missing values are NaN32.
  • attrib::OrderedDict{String,Any}: output attributes (units, long_name, …).
  • is3d::Bool: true for variables with a vertical dimension.
  • to_pressure::Bool: for a 3D variable, whether it is interpolated to pressure levels when TimeSeriesConfig.pressure_levels is set (see InputVariable).

See also LazyVariable for variables computed only when they are processed, and field.

Example

v = load_run(cfg, "RUN1").variables["prsurf"]
v.is3d, size(v.data)   # (false, (72, 46, 240))

w = VariableData(zeros(Float32, 4, 3, 12), OrderedDict{String,Any}("units" => "1"), false)
w.to_pressure          # true

PlanetPostStats.TimeSeriesMeSd.load_run — Method
load_run(cfg::TimeSeriesConfig, run::AbstractString) -> RunData

Reads all variables of all input groups of run for every month of cfg.sim_period into memory, applies the variable scale factors, and evaluates the derived variables.

Procedure

  1. Constructs the expected input path of every (group, month) and checks which files exist. The monthly record ends with the last month for which any file exists; months with missing files inside the record are kept as NaN32 (gaps).
  2. Probes the first available file of each group for the variables, their dimensionality and attributes, and the grid (coordinates, cell area axyp).
  3. Reads every file once (one open per file, all variables of the group) and stores each variable at a fixed position, independent of which files exist.
  4. Evaluates cfg.derived in order.

Memory: 4 × nlon × nlat × (n2d + nlev × n3d) × nmonths bytes for one run (e.g. ≈ 0.9 GB for 72 × 46 × 40, seven 3D variables, 240 months). Only one run is held in memory at a time by run_timeseries_statistics.

Arguments

  • cfg::TimeSeriesConfig: the configuration.
  • run::AbstractString: run identifier (one of cfg.runs).

Returns

A RunData.

Example

rd = load_run(cfg, "MarsDustRun1")
rd.months[end]                          # last month with data
size(rd.variables["Clay"].data)         # (72, 46, 40, 240)
